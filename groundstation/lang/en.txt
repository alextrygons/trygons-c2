# =============================================================================
#  Trygons C2 ground station - ENGLISH screen texts
# =============================================================================
#  How to edit (the same rules for el.txt):
#    * one entry per line:   key = text
#    * the KEY (left of "=") is used by the program - never change it
#    * the TEXT (right of "=") is what the screen shows - change it freely
#    * {name} in a text is filled in by the program (a number, a name ...):
#      keep every {name} of an entry, you may move it inside the text
#    * \n starts a new line on the screen
#    * lines starting with # are comments
#  After editing: restart the ground station (or switch the language twice).
#  The tests (groundstation/test_lang.py) check that el.txt and en.txt have
#  the same keys and the same {names}.
#  Logs, the audit, the protocol and test reports always stay in English.
# =============================================================================
